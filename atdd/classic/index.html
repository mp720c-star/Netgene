Vehicle search

Search the shared index of cars, trucks, bikes, ATVs, and snowmobiles. Cars and trucks use the generic automotive DTC, job, and how-to guides. Bikes, ATVs, 3-wheelers, and sleds with a CDI pinout open a separate ignition view — never an OBD code.

What's wrong? Symptom repair

Search or browse a system-based repair database: what the symptom means, ranked causes, and a test for each cause (tool, what to check, good vs bad, and a spec). Meanings that a public government source supports are labeled cited. Everything else is labeled general guidance and must be verified with the service manual for your vehicle.

Use on a computer
Same app on a PC. Useful when you want a bigger screen or an offline folder.
  1. Fastest: on the computer, open Chrome or Edge and go to the same page you are reading now. Bookmark it.
  2. Offline folder: on the computer open GitHub → Code → Download ZIP. Unzip it. Double-click GET_ON_COMPUTER.bat (Windows) or web/index.html (any computer).
  3. Windows app window: after the unzip, install Node.js LTS, then double-click windows\START_APP_FOR_TESTING.bat. For a Setup EXE, use windows\BUILD_WINDOWS_INSTALLER.bat.
